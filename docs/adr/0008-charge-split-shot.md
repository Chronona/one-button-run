# 0008. チャージ投擲: 少ない投擲数で壊すと次ステージで弾が分裂する

## Status

proposed（2026-10-02）

> このリポジトリの現時点の判断を記録したものです。一般的な best practice の主張ではありません。

## Context

チャージ投擲モード（`modes/charge/`）は、押下で構え、解放で射出する。標的を壊すと残弾が戻る。
1発目を試射として弾道を補正し、2発目で当てる遊びが生まれているが、「1発で決める」ことに
見返りがなく、試射が常に最適解になっている。

## Decision

1. 各ステージで投擲した回数（外れも数える）を数え、ステージ全破壊時に次ステージの分裂数を決める。
   - 1発 → 3分裂
   - 2発 → 2分裂
   - 3発以上 → 分裂なし
2. 分裂は発射から 0.4 秒後に起きる。本体の弾道は変えず、速度を ±0.14rad 回した弾を足す
   （3分裂は左右に1発ずつ、2分裂は上側に1発）。
3. 本体の弾道を変えないため、「分裂がなくても当たる射線」は分裂があっても必ず当たる。
   ボット（`modes/charge/bot.gd`）の前向き模擬は変更せず有効なままになる。
4. 新しい演出イベント `split` を `required_feedback_events` に足す（既存の `HitParticles` / `HitSE` を流用）。
5. 分裂数はステージ表示に `x3` のように出す。
6. 分裂数は発射時点で確定し、飛行中にステージが進んでもその弾の分裂数は変わらない。

### 今回やらないこと

- 「投擲回数が少ないほど高得点」。現在のスコアは `core/game_host.gd` が経過時間で加算しており、
  モードが加点できない。モードから加点できるフックは `core/` の変更を伴うので、別の変更で扱う。
- 弾道ゴースト、ヒットストップ、画面ブレなどの派手な演出。

## Consequences

- 試射が最適とは限らなくなる。狙いを外した時の損が、残弾に加えて次ステージの有利さにも及ぶ。
- 分裂は当たりやすさを上げるので、後続ステージの難易度が下がる。難易度の実体は角度メーターの速度で、
  これは変えていない。バランスは実プレイで見直す前提。

## Confirmation

- `tests/contract/test_charge_split.gd` が、投擲数と分裂数の対応と、1発破壊後の分裂数を検査する（CI が落とす）。
- `tests/contract/test_feedback.gd` が `split` イベントの演出解決を検査する（CI が落とす）。
- 弾の増え方・見た目・体感は実プレイでの確認が必要で、CI では見ていない。
